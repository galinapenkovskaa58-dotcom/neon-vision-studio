# Видео-портфолио для AI Видео & Клипы

## Что делаем

Создаём полностью отдельную систему видео-работ — независимую от текущего фото-портфолио. Новая таблица в БД, новый раздел в админке, новый блок на публичной странице `/ai-video`.

## 1. База данных

Новая таблица `video_portfolio`:

| Поле | Тип | Назначение |
|---|---|---|
| `id` | uuid | первичный ключ |
| `title` | text | заголовок работы |
| `description` | text (nullable) | короткое описание |
| `category` | text | одна из 6 категорий (см. ниже) |
| `cover_url` | text | URL обложки (превью) |
| `video_url` | text | ссылка на видео (YouTube / VK / прямой mp4) |
| `sort_order` | int | порядок отображения |
| `is_active` | bool | активно / скрыто |
| `created_at`, `updated_at` | timestamptz | служебные |

**RLS-политики:**
- Все могут читать только активные записи (`is_active = true`)
- Админы (через `has_role`) — полный CRUD

Триггер `update_updated_at_column` для `updated_at`.

**Storage:** для обложек используем существующий публичный бакет `portfolio` (папка `video-covers/`), отдельный бакет не нужен.

## 2. Категории (фиксированный список)

- AI-видеоролики
- Музыкальные клипы
- Рекламные ролики
- Видео для соцсетей
- Имиджевые видео
- Истории и storytelling

Хранятся как `text` в БД (а не enum) — проще расширять. В админке — выпадающий список с этими значениями.

## 3. Админка

Новый раздел `AdminVideoPortfolio.tsx`, добавляется в `Admin.tsx` как новая вкладка «Видео-портфолио».

Возможности:
- Список всех видео-работ с миниатюрой обложки, заголовком, категорией, статусом
- Кнопка «Добавить» → форма (заголовок, описание, категория из списка, загрузка обложки в storage, ссылка на видео, порядок, чекбокс активно)
- Редактирование и удаление каждой записи
- Drag-n-drop сортировка (как в существующем `AdminPortfolio` через `SortableWrapper`)
- Превью обложки прямо в форме

## 4. Публичная страница `/ai-video`

Новый компонент `VideoPortfolio.tsx` встраивается в `AiVideo.tsx` между блоком фич и отзывами.

**Структура:**
- Заголовок «Портфолио видео» с градиентным неоновым текстом
- Подзаголовок-подсказка
- Ряд кнопок-фильтров: «Все» + 6 категорий (стиль как у фильтров в `Portfolio.tsx` — `neon-glow-btn` для активной, `glass` для остальных)
- Сетка карточек

**Карточка видео:**
- Соотношение 16:9, тёмный фон, `glass` + неоновая рамка с лёгким свечением (cyan/purple/pink по очереди как в фото-портфолио)
- Обложка с `object-cover`
- Затемняющий градиент снизу
- Play-кнопка по центру (круглая, неоновая, увеличивается при ховере)
- Снизу: название, категория-чип, короткое описание
- Hover: подъём карточки + усиление свечения (framer-motion)

**Адаптив:**
- Мобильные (<640px): 1 колонка
- Планшет (640–1024px): 2 колонки
- Десктоп (≥1024px): 3 колонки
- Отступы и размер play-кнопки масштабируются

**Открытие видео:**
- YouTube/VK ссылки распознаём по домену → открываем в модалке (Dialog) с встроенным `<iframe>` через embed-URL
- Прямые mp4 → модалка с `<video controls autoplay>`
- Если ссылка не распознана — открывается в новой вкладке

Модалка: `max-w-4xl`, `aspect-video`, тёмный фон с неоновой рамкой, кнопка закрытия в углу.

## Что НЕ делаем

- Не трогаем существующую таблицу `portfolio` и компоненты `Portfolio.tsx`, `PortfolioNode.tsx`, `PortfolioLightbox.tsx`
- Не добавляем загрузку самих видеофайлов в storage (только ссылки на внешние плееры или внешние mp4) — это сильно увеличило бы стоимость хранения
- Не делаем автоплей превью при ховере на этом этапе (можно добавить позже)
